# Світло Черкаси — iOS-застосунок і віджети

Графіки погодинних відключень (ГПВ) для підчерг 1.1–6.2 з офіційного сайту АТ «Черкасиобленерго».

## Збірка (потрібні macOS + Xcode 15+)
1. `brew install xcodegen`
2. У `project.yml` змініть **BUNDLE_PREFIX** та **APP_GROUP_ID** на свої (напр. `com.ivan` / `group.com.ivan.CherkasyLight`).
3. `cd CherkasyLight && xcodegen generate && open CherkasyLight.xcodeproj`
4. Xcode → Settings → Accounts: додайте Apple ID. У Signing & Capabilities для **обох** таргетів (CherkasyLight, CherkasyLightWidget) оберіть свою Team.
   Capability **App Groups** з вашим APP_GROUP_ID має бути в обох (xcodegen додає entitlements, Xcode зареєструє групу автоматично).
5. Підключіть iPhone, оберіть його, схема CherkasyLight, ⌘R. На iPhone: Налаштування → Загальні → VPN і керування пристроєм → довіряти розробнику (і режим розробника).
6. Тести: ⌘U (таргет CherkasyLightTests, живий сайт не потрібен).
7. Віджет: довге натискання на домашньому екрані → «+» → «Світло Черкаси»; «Змінити віджет» → оберіть підчергу.

## Джерело даних
Окремого API на сайті знайдено не було. Щоденні графіки публікуються як текстові новини
(«Графік погодинних відключень (ГПВ) на 10 листопада»): `/news?lang=uk` → допис → рядки `1.1 00:00 - 02:00, ...`.
Застосунок читає список новин, вибирає найновіший допис ГПВ для кожної доби (сьогодні…+2) і парсить рядки.
Усі інтервали в дописах — відключення; решта доби — світло є. Відсутній допис або підчерга = «невідомо», не «світло є».
PDF `/perelik-gpv` містять лише адреси по чергах, не час.

## Структура
- `Shared/` — моделі, парсер, мережа, кеш, репозиторій, спільні view (застосунок + віджет + тести)
- `App/` — SwiftUI-екрани, стан, фонове оновлення
- `Widget/` — WidgetKit, AppIntent для вибору підчерги
- `Tests/` — XCTest на фікстурах (текст взято з реального допису)

## Обмеження
- Код **не компілювався і не запускався** (автор не мав Xcode); можливі помилки збірки.
- Реальний HTML сайту не бачили (лише відрендерений текст): `parseNewsList` написано за припущенням `<a href="/media/...">` + дата `dd.MM.yyyy HH:mm` поруч. Якщо сайт рендерить список через JS, застосунок покаже «Структура сайту змінилася».
- Віджет оновлюється так, як дозволяє iOS; фонові завдання без гарантій за часом.
- Формат дописів із групуванням «по чергах» (не підчергах) не підтримується навмисно.
